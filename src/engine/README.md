# Design engine

Pure TypeScript. No React, no DOM, no Next.js, no network. Everything that
draws pixels for this app goes through here so single mode, batch previews and
print export cannot drift.

Flow: `Set` (input + style) → `expand()` → one `Design` per member →
`renderDesign()` / `exportPrintPng()` / `renderMockup()`.

- Coordinates are print pixels at 300 DPI. Canvas is a square of
  `maxPx(sizeClass)` (adult 29 cm, kids 0–1 18 cm, kids 1–9 20 cm).
- Layers must stay inside the 3% safe area; `isWithinSafeArea()` guards export.
- Layer ids from the Collage template are stable: `numeral, clipart, top,
  ordinal, occasion, bottom`. Member `overrides` are keyed by these ids.
- Fonts: only families in `fonts.ts`, files in `public/fonts`. Register them
  in any new renderer via `registerFonts()`.
- Golden tests live in `tests/engine/__golden__`. Regenerate deliberately with
  `UPDATE_GOLDEN=1 pnpm test` and inspect the PNGs before committing. Mockup
  goldens (`mockup-*.png`) are regenerated by deleting them from
  `tests/engine/__golden__` and rerunning the mockup test.
